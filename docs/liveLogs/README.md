# Session logs from phones

The session logs the phones exported during the makers' live runs 1–6 (2026-11-07 to 2026-11-10), one NDJSON line per event, as each phone's app records it (what a line holds: [`docs/guide/running-on-phones.md`](../guide/running-on-phones.md#the-session-log-what-each-phone-records-and-how-to-get-it-off-the-phone)). [`.scratch/live-test-1/findings.md`](../../.scratch/live-test-1/findings.md) analyses them and says which phone and run each file comes from: run 1 is in `Client_IPhone12/`, `Client_Iphone14/` and `Host_Iphone15promax/`, run 2 in the two `*-825T-*` files, run 3 in `withoutandwithturn/`, run 4 in `02edc2eTest/`, run 5 in the two `mgc-XHZE-*` files, run 6 in `microphoneFix/`. The eleven 37-byte `Text*.txt` and `text*.txt` files hold only a log's file name: the iPhone's share sheet saved them beside the real logs (findings §4). A log holds the kind of phone, its connection details, the table code and the names typed in, but no IP address.
